## 🚀 Overview

This project uses a **PyTorch-based Artificial Neural Network (ANN)** to predict the electrical energy output of a **Combined Cycle Power Plant (CCPP)** from environmental conditions.

The model learns the relationship between atmospheric variables such as **temperature, exhaust vacuum, ambient pressure, and relative humidity** and the plant's electrical energy output.

This project demonstrates a complete **Deep Learning regression pipeline**, from data preprocessing and feature scaling to ANN training, evaluation, and visualization.

### 🎯 Objective

> Build a deep learning regression model that can accurately predict power generation under different environmental conditions.

---

# 🏭 Problem Statement

Combined Cycle Power Plants operate under constantly changing environmental conditions.

Factors such as:

* 🌡️ Temperature
* 💨 Exhaust Vacuum
* 🌬️ Ambient Pressure
* 💧 Relative Humidity

can significantly affect the electrical energy generated by the plant.

Accurately predicting power output can help with:

* 📊 Operational planning
* ⚙️ Energy production optimization
* 📈 Performance monitoring
* 💡 Improved decision-making
* 🔋 Efficient power management

The goal of this project is to develop an **ANN regression model** capable of learning these relationships and predicting electrical energy output.

# 🧠 Artificial Neural Network

The model is a fully connected **Artificial Neural Network** designed for regression.

### Architecture

```text
             INPUT
        ┌───────────────┐
        │  4 Features   │
        │ AT │ V │ AP │ RH
        └───────┬───────┘
                │
                ▼
        ┌───────────────┐
        │ Hidden Layer  │
        │    ReLU       │
        └───────┬───────┘
                │
                ▼
        ┌───────────────┐
        │ Hidden Layer  │
        │    ReLU       │
        └───────┬───────┘
                │
                ▼
```

### Model Components

* 🔢 **Input Layer:** 4 neurons
* 🧠 **Hidden Layers:** Fully connected layers
* ⚡ **Activation:** ReLU
* 🎯 **Output Layer:** 1 neuron
* 📈 **Task:** Regression

# 📏 Data Preprocessing

Before training the ANN, the input features are standardized using **StandardScaler**.

The standardization process transforms the features so they have approximately:

```text
Mean = 0
Standard Deviation = 1
```

This helps neural networks train more efficiently when input features have different scales.

### Preprocessing Pipeline

```text
Raw Features
     ↓
Train-Test Split
     ↓
Fit StandardScaler on Training Data
     ↓
Transform Training Data
     ↓
Transform Test Data
     ↓
PyTorch Tensors
```

> The scaler is fitted only on the training data to avoid data leakage.

---

# 🔥 Model Training

The ANN is trained using **mini-batch gradient-based optimization**.

### Loss Function

The project uses:

**Mean Squared Error (MSE)**

```text
MSE = Average[(Actual - Predicted)²]
```

MSE penalizes larger prediction errors more strongly and is commonly used for regression problems.

### Optimizer

**Adam Optimizer**

Adam dynamically adapts the learning rate for each parameter and is widely used for training neural networks.

### Training Pipeline

```text
Training Data
      ↓
Mini-Batches
      ↓
ANN Forward Pass
      ↓
Predicted Power Output
      ↓
Calculate MSE Loss
      ↓
Backpropagation
      ↓
Adam Optimization
      ↓
Update Model Weights
```

# 📊 Evaluation Metrics

The trained model is evaluated using three regression metrics.

### 1. Mean Squared Error — MSE

Measures the average squared difference between actual and predicted values.

**Lower is better.**

### 2. Root Mean Squared Error — RMSE

RMSE is the square root of MSE and is expressed in the same unit as the target variable.

**Lower is better.**

### 3. R² Score

R² measures how much of the variation in the target variable is explained by the model.

**Higher is better.**
